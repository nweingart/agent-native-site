# useAgentStream

Connects to an NDJSON event stream and drives an `AgentTimeline` automatically. Combines `useAgentSteps` with a streaming fetch, returning ready-to-spread `props` plus connection status and reconnection controls.

## Basic Usage

<CodeBlock
  code={`import { useAgentStream, AgentTimeline } from 'agent-native';

function LiveAgentView() {
  const { props, status, error } = useAgentStream({
    url: '/api/agent/stream',
    showElapsedTime: true,
    showToolCalls: true,
  });

  return (
    <div>
      {status === 'error' && <p className="text-red-500">{error?.message}</p>}
      <AgentTimeline {...props} />
    </div>
  );
}`}
  lang="tsx"
  filename="LiveAgentView.tsx"
/>

### Conditional Streaming

Enable or disable the stream connection based on application state.

<CodeBlock
  code={`const [isRunning, setIsRunning] = useState(false);

const { props, status, disconnect, reconnect } = useAgentStream({
  url: '/api/agent/stream',
  enabled: isRunning,       // only connect when true
  reconnect: true,          // auto-reconnect on disconnect
  reconnectInterval: 3000,  // wait 3s between retries
  maxReconnects: 5,         // give up after 5 attempts
  onError: (err) => console.error('Stream error:', err),
  onOpen: () => console.log('Connected'),
  onClose: () => console.log('Disconnected'),
});`}

## How It Works

1. Opens a `fetch()` request with `ReadableStream` to the provided URL
2. Reads NDJSON lines (newline-delimited JSON), parsing each as an `AgentEvent`
3. Dispatches each event into `useAgentSteps` internally
4. Returns the same `props` as `useAgentSteps`, plus connection status controls
5. On disconnect, optionally retries based on `reconnect` / `maxReconnects` settings

<Callout variant="info">
  The stream endpoint must return newline-delimited JSON (NDJSON). Each line should be a valid `AgentEvent` object. Example: `{"type":"step.started","step":{"id":"1","label":"Scanning..."}}\n`
</Callout>

<Callout variant="tip">
  For more control, use `useAgentSteps` directly and wire up your own transport (WebSocket, SSE, polling) to call `dispatch`.
</Callout>
