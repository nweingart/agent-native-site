# useReducedMotion

Returns `true` when the user has `prefers-reduced-motion: reduce` enabled. Reactive — updates instantly if the preference changes at runtime. SSR-safe.

## Basic Usage

<CodeBlock
  code={`import { useReducedMotion } from 'agent-native';

function AnimatedIcon({ status }) {
  const prefersReduced = useReducedMotion();

  if (status === 'running') {
    return prefersReduced
      ? <PulsingDot />    // Gentle opacity pulse
      : <SpinningIcon />; // Full rotation animation
  }

  return <StaticIcon status={status} />;
}`}

## Return Value

Returns a `boolean`:
- `true` — user prefers reduced motion
- `false` — no preference (default, and SSR fallback)

## How It Works

1. On mount, queries `window.matchMedia('(prefers-reduced-motion: reduce)')`
2. Reads the initial `.matches` value
3. Attaches a `change` event listener that updates state reactively
4. Returns `false` during SSR (no `window` available)
5. Cleans up the listener on unmount

## Internal Usage

agent-native uses this hook in two places:

- **TimelineStep** — swaps `an-spin` (rotation) for `an-pulse` (opacity) on the running indicator
- **useVisualMemory** — skips animation entirely, jumping `progress` straight to 1

This means the entire library automatically respects the user's motion preferences with zero configuration.
