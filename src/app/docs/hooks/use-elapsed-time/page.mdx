# useElapsedTime

Returns a live-updating formatted time string. Counts up while running and freezes when completed. Used internally by TimelineStep for elapsed time display.

## Output Format

| Duration | Output |
|----------|--------|
| No `startedAt` | `"0s"` |
| Under 1 minute | `"Xs"` (e.g. `"42s"`) |
| Under 1 hour | `"Xm Ys"` (e.g. `"3m 12s"`) |
| 1 hour+ | `"Xh Ym Zs"` (e.g. `"1h 5m 30s"`) |

## Parameters

<PropsTable
  props={[
    { name: "startedAt", type: "number | undefined", description: "Unix timestamp (ms) when the timer started. Returns \"0s\" when undefined." },
    { name: "completedAt", type: "number | undefined", description: "Unix timestamp (ms) when the timer stopped. Freezes the display when set." },
    { name: "interval", type: "number", default: "1000", description: "Update interval in milliseconds." },
  ]}
/>

## Return Value

Returns a `string` — the formatted elapsed time. Updates every `interval` ms while running.

## Behavior

- Returns `"0s"` when `startedAt` is `undefined`
- Starts a `setInterval` that re-renders every `interval` ms
- When `completedAt` is provided, calculates the difference between `completedAt` and `startedAt` (no interval)
- Cleans up the interval on unmount or when `completedAt` is set

<Callout variant="tip">
  Use this with `AgentStep.startedAt` and `AgentStep.completedAt` timestamps. Or pass `showElapsedTime` to AgentTimeline and let it handle the wiring automatically.
</Callout>
