# useVisualMemory

Tracks value transitions and exposes animated progress so your UI can blend between states. Used internally by TimelineStep to smoothly morph status indicators (spinner to checkmark, dot to spinner, etc.).

## Basic Usage

<CodeBlock
  code={`import { useVisualMemory } from 'agent-native';

function StatusIndicator({ status }) {
  const { current, previous, progress, isTransitioning } = useVisualMemory(status);

  return (
    <div style={{ opacity: progress }}>
      {current === 'complete' ? '✓' : current === 'running' ? '⟳' : '○'}
    </div>
  );
}`}
  lang="tsx"
  filename="StatusIndicator.tsx"

## How It Works

1. When `value` changes, the hook stores the old value as `previous` and starts a `requestAnimationFrame` loop
2. Each frame, it calculates elapsed time and applies the easing function to produce `progress` (0 to 1)
3. When `progress` reaches 1, `isTransitioning` becomes `false`
4. All easing functions are pure math — no CSS transitions, no spring physics libraries

<Callout variant="info">
  When `prefers-reduced-motion: reduce` is detected, the hook automatically skips animation — `progress` jumps to 1 immediately and `isTransitioning` stays `false`.
</Callout>

## Use Cases

- **Status indicator morphing** — blend between spinner, checkmark, and error icons
- **Color transitions** — interpolate between status colors using `progress`
- **Content crossfades** — fade out old content, fade in new content based on `progress`
- **Custom step animations** — use `previous` and `current` to determine transition direction
