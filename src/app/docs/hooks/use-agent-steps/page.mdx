# useAgentSteps

A reducer-based hook that manages agent timeline state. Accepts `AgentEvent` dispatches and returns ready-to-spread `props` for `AgentTimeline`. Handles step creation, tool call tracking, tier management, and approval gates.

## Examples

### Manual Dispatch

Wire up buttons or WebSocket messages to dispatch events that build the timeline incrementally.

<LiveDemo title="Manual Dispatch">
  <AgentStepsDemo />

<CodeBlock
  code={`const { props, dispatch, reset } = useAgentSteps({ showElapsedTime: true });

// Start a step
dispatch({ type: 'step.started', step: { id: 'analyze', label: 'Analyzing code' } });

// Update a step
dispatch({ type: 'step.updated', stepId: 'analyze', fields: { description: '47 files scanned' } });

// Complete a step
dispatch({ type: 'step.completed', stepId: 'analyze' });

// Reset everything
reset();`}
  lang="tsx"
/>

### With Tool Calls

Track tool calls within steps. The timeline shows tool calls nested inside their parent step.

<CodeBlock
  code={`const { props, dispatch } = useAgentSteps({ showToolCalls: true });

// Start a step
dispatch({ type: 'step.started', step: { id: 'edit', label: 'Editing files' } });

// Start a tool call within the step
dispatch({
  type: 'tool.started',
  stepId: 'edit',
  toolCall: { id: 'tc-1', name: 'read_file', input: { path: 'src/app.ts' } },
});

// Complete the tool call
dispatch({
  type: 'tool.completed',
  stepId: 'edit',
  toolCallId: 'tc-1',
  output: 'File contents (89 lines)',
});`}
  lang="tsx"
/>

## How It Works

1. Internally uses `useReducer` with an `AgentEvent` discriminated union
2. Each event type maps to a specific state transition (e.g. `step.started` pushes a new step with `status: 'running'`)
3. The `props` object is memoized and includes `steps`, `tiers`, `approvalRequest`, plus any options passed in
4. Timestamps (`startedAt`, `completedAt`) are set automatically when not provided

## AgentEvent Types

<CodeBlock
  code={`type AgentEvent =
  | { type: 'step.started';  step: Pick<AgentStep, 'id' | 'label'> & Partial<AgentStep> }
  | { type: 'step.updated';  stepId: string; fields: Partial<AgentStep> }
  | { type: 'step.completed'; stepId: string; status?: 'complete' | 'error' | 'skipped' | 'cancelled'; error?: string }
  | { type: 'tool.started';  stepId: string; toolCall: Pick<ToolCall, 'id' | 'name' | 'input'> }
  | { type: 'tool.updated';  stepId: string; toolCallId: string; fields: Partial<ToolCall> }
  | { type: 'tool.completed'; stepId: string; toolCallId: string; output?: unknown; error?: string }
  | { type: 'tier.started';  tier: Pick<StepTier, 'id' | 'stepIds'> & Partial<StepTier> }
  | { type: 'tier.completed'; tierId: string }
  | { type: 'approval.requested'; request: ApprovalRequest }
  | { type: 'approval.resolved'; requestId: string; decision: 'approved' | 'rejected' }
  | { type: 'artifact.added'; stepId: string; artifact: Artifact }
  | { type: 'reset' };`}
  lang="typescript"
/>
