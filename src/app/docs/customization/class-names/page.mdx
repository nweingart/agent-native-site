# classNames

Every agent-native component accepts a `classNames` prop for targeted styling of internal elements.

## How It Works

Components accept two styling props:

- **`className`** — Shortcut that applies to the root element only
- **`classNames`** — Structured object targeting specific internal elements

Both can be used together. They merge via `cn()` (clsx) with the library's defaults:

<CodeBlock
  code={`<AgentTimeline
  className="my-4"
  classNames={{
    step: "rounded-xl",
    indicator: "ring-2 ring-offset-2",
  }}
/>`}
  lang="tsx"
/>

<Callout variant="info">
  Library styles use `@layer agent-native`, so your classes and Tailwind utilities automatically win — no `!important` needed.
</Callout>
