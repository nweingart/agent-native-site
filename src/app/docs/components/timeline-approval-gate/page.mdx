# TimelineApprovalGate

A human-in-the-loop approval prompt. Renders a title, optional description, and Approve/Reject buttons. Used by AgentTimeline when you pass the `approvalRequest` prop, or standalone for custom approval flows.

<FeatureList
  features={[
    "Approve and Reject actions with callback handlers",
    "Optional description for context",
    "Purple accent border and glow (approval status color)",
    "Fade-in animation on mount",
    "Buttons only render when handlers are provided",
    "Full class override support for custom styling",
    "Data attributes for targeting",
  ]}
/>

## Basic Usage

<CodeBlock
  code={`import { TimelineApprovalGate } from 'agent-native';
import type { ApprovalRequest } from 'agent-native';

const request: ApprovalRequest = {
  id: 'gate-1',
  stepId: 'deploy',
  title: 'Deploy to production?',
  description: '12 files changed, all tests passing.',
  createdAt: Date.now(),
};

function MyApproval() {
  return (
    <TimelineApprovalGate
      request={request}
      onApprove={(req) => console.log('Approved:', req.id)}
      onReject={(req) => console.log('Rejected:', req.id)}
    />
  );
}`}
  lang="tsx"
  filename="MyApproval.tsx"
/>

## Using with AgentTimeline

Typically you wire approval through AgentTimeline rather than using this component directly:

<CodeBlock
  code={`const [approval, setApproval] = useState<ApprovalRequest | undefined>({
  id: 'gate-1',
  stepId: 'review',
  title: 'Apply changes?',
  description: '3 files modified',
  createdAt: Date.now(),
});

<AgentTimeline
  steps={steps}
  approvalRequest={approval}
  onApprove={(req) => {
    setApproval(undefined);
    // Continue the workflow...
  }}
  onReject={(req) => {
    setApproval(undefined);
    // Cancel or rollback...
  }}
/>`}
  lang="tsx"
/>

AgentTimeline renders the approval gate inline at the bottom of the timeline, below the last step.

## CSS Classes

| Class | Description |
|-------|-------------|
| `an-timeline__approval` | Root container (purple border, approval background, fade-in) |
| `an-timeline__approval-title` | Title text (bold, purple) |
| `an-timeline__approval-description` | Description text (secondary color) |
| `an-timeline__approval-actions` | Button row container |
| `an-timeline__approval-btn` | Base button styles |
| `an-timeline__approval-btn--approve` | Approve button (green background) |
| `an-timeline__approval-btn--reject` | Reject button (red background) |

## Accessibility

- Approve and Reject are real `<button>` elements with visible labels
- The gate container uses fade-in animation (respects `prefers-reduced-motion`)
- Buttons are focusable and respond to Enter/Space
