# TimelineStep

The core building block of AgentTimeline. Renders a single step with a status indicator, label, optional description, and elapsed time. Use it standalone when you need individual step rows outside of a full timeline.

<FeatureList
  features={[

## Basic Usage

<CodeBlock
  code={`import { TimelineStep } from 'agent-native';
import type { AgentStep } from 'agent-native';

const step: AgentStep = {
  id: 'scan',
  label: 'Scanning repository',
  status: 'running',
  description: 'Analyzing 847 files...',
  startedAt: Date.now(),
};

function MyStep() {
  return <TimelineStep step={step} />;

## Examples

### All Status States

Each status gets a distinct visual indicator: spinners for running, checkmarks for complete, X marks for errors, and dots for pending/skipped/cancelled.

### Clickable Steps

Pass `onClick` to make steps interactive. This adds `role="button"`, `tabIndex={0}`, and keyboard event handlers. Combine with `isActive` to highlight the selected step.

<LiveDemo title="Clickable Steps">
  <ClickableStepDemo />
</LiveDemo>

<CodeBlock
  code={`const [active, setActive] = useState<string | null>(null);

<TimelineStep
  step={step}
  isActive={active === step.id}
  onClick={(s) => setActive(s.id)}
/>`}
  lang="tsx"
/>

### Elapsed Time

Set `showElapsedTime` to display a live counter. The timer runs while `status` is `running` and freezes when `completedAt` is set.

<LiveDemo title="Elapsed Time">
  <ElapsedStepDemo />
</LiveDemo>

<CodeBlock
  code={`<TimelineStep
  step={{
    id: 'build',
    label: 'Building search index',
    status: 'running',
    startedAt: Date.now() - 15000,
  }}
  showElapsedTime
/>`}
  lang="tsx"

### Custom Renderers

Replace the default indicator or body content with your own components using `renderIndicator` and `renderContent`.

<LiveDemo title="Custom Renderer">
  <CustomRendererStepDemo />
</LiveDemo>

<CodeBlock
  code={`<TimelineStep
  step={step}
  renderIndicator={(s) => (
    <div className="w-6 h-6 rounded-full bg-accent/20 flex items-center justify-center text-xs">
      {s.status === 'running' ? '~' : s.status === 'complete' ? '+' : '-'}

  )}
  renderContent={(s) => (
    <div className="ml-3">
      <div className="font-semibold text-sm">{s.label}</div>
      <div className="text-xs text-muted-foreground">Region: {s.description}</div>
    </div>
  )}
/>`}

## CSS Classes

| Class | Description |
|-------|-------------|
| `an-timeline__step` | Root step container |
| `an-timeline__step--{status}` | Status modifier (e.g. `--running`, `--complete`) |
| `an-timeline__step--active` | Applied when `isActive` is true |
| `an-timeline__step--clickable` | Applied when `onClick` is provided |
| `an-timeline__indicator` | Status indicator circle |
| `an-timeline__indicator--{status}` | Status-specific indicator styling |
| `an-timeline__step-body` | Body wrapper (label + description + elapsed) |
| `an-timeline__step-label` | Step label text |
| `an-timeline__step-description` | Step description text |
| `an-timeline__step-error` | Error message text |
| `an-timeline__step-elapsed` | Elapsed time counter |

## Accessibility

- When `onClick` is provided, the step gains `role="button"` and `tabIndex={0}`
- Enter and Space keys trigger the click handler
- Running steps are marked `aria-busy="true"`
- Elapsed time updates use `aria-live="polite"`
- `prefers-reduced-motion: reduce` swaps spin animation for a gentle pulse
