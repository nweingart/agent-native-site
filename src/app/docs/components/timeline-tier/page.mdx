# TimelineTier

Groups multiple steps that execute in parallel. Renders them inside a bordered container with a header showing the tier label and a "N parallel" badge. Used by AgentTimeline when you pass the `tiers` prop, or standalone for custom layouts.

<FeatureList
  features={[
    "Visual grouping for concurrent steps",
    "Automatic parallel count badge",
    "Custom header rendering",
    "Passes through all TimelineStep props (click, elapsed, renderers)",
    "Full classNames override support",
    "Data attributes for tier targeting",
  ]}
/>

## Basic Usage

<CodeBlock
  code={`import { TimelineTier } from 'agent-native';
import type { AgentStep, StepTier } from 'agent-native';

const steps: AgentStep[] = [
  { id: 'lint', label: 'ESLint', status: 'complete', description: '0 errors' },
  { id: 'typecheck', label: 'TypeScript', status: 'complete' },
  { id: 'test', label: 'Vitest', status: 'running', description: '47/52 passing' },
];

const tier: StepTier = {
  id: 'checks',
  label: 'CI Checks',
  stepIds: ['lint', 'typecheck', 'test'],
};

function MyTier() {
  return <TimelineTier tier={tier} steps={steps} />;
}`}
  lang="tsx"
  filename="MyTier.tsx"
/>

<Callout variant="info">
  The `steps` array should contain **all** steps. TimelineTier automatically filters to only render steps whose IDs are in `tier.stepIds`.
</Callout>

## Using with AgentTimeline

Most commonly, you won't use TimelineTier directly — instead pass `tiers` to AgentTimeline:

<CodeBlock
  code={`<AgentTimeline
  steps={allSteps}
  tiers={[
    { id: 'checks', label: 'Quality Checks', stepIds: ['lint', 'typecheck', 'test'] },
    { id: 'deploy', label: 'Deployment', stepIds: ['us-east', 'eu-west'] },
  ]}
/>`}
  lang="tsx"
/>

AgentTimeline handles the orchestration — it renders tiered steps inside `TimelineTier` and non-tiered steps as standalone `TimelineStep` components, with connectors between them.
