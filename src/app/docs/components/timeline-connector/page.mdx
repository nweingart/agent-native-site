# Connectors

Vertical lines drawn between steps to show sequential flow. AgentTimeline renders connectors automatically using CSS pseudo-elements — no extra components needed. The connector color follows each step's status, creating a continuous progress trail.

    "First step: line below only. Last step: line above only",
    "Automatically hidden for steps inside tiers",
    "Disabled via showConnectors={false}",
    "Respects reduced motion preferences",
  ]}
/>

## How It Works

AgentTimeline adds a `::before` pseudo-element to each step that draws a 2px vertical line through the indicator column. The indicator circle sits on top (via `z-index`) so the line appears to connect the circles seamlessly.

Each step receives a `connectorSegments` value that controls which parts of the line are visible:

| Position | Segments | Effect |
|----------|----------|--------|
| First step | `below` | Line from indicator center to bottom edge |
| Middle steps | `both` | Line from top to bottom (full height) |
| Last step | `above` | Line from top edge to indicator center |
| Single step | `none` | No line |
| Inside a tier | `none` | No line (tiers have their own border) |

## Disabling Connectors

Set `showConnectors={false}` to hide all connector lines:

<LiveDemo title="Connectors Disabled">
  <ConnectorDisabledDemo />
</LiveDemo>

<CodeBlock
  code={`// Connectors are on by default
<AgentTimeline steps={steps} />

// Disable connectors
<AgentTimeline steps={steps} showConnectors={false} />`}
  lang="tsx"
/>

When disabled, the root element gets the `an-timeline--no-connectors` class and all steps receive `connectorSegments="none"`.

---

## CSS Classes

| Class | Description |
|-------|-------------|
| `an-timeline__step::before` | The connector line pseudo-element on each step |
| `an-timeline__step--connector-both` | Full-height line (top to bottom) |
| `an-timeline__step--connector-below` | Line from indicator center to bottom (first step) |
| `an-timeline__step--connector-above` | Line from top to indicator center (last step) |
| `an-timeline__step--connector-none` | No connector line |
| `an-timeline--no-connectors` | Added to root when `showConnectors={false}` |
| `an-timeline__step--complete::before` | Green connector line for completed steps |
| `an-timeline__step--error::before` | Red connector line for error steps |

## Customizing Connector Appearance

Override the connector line with CSS variables or custom styles:

<CodeBlock
  code={`/* Change connector color */
.an-timeline__step::before {
  background-color: var(--my-connector-color);
}

/* Change connector width */
.an-timeline__step::before {
  width: 3px;
  /* Adjust left position to keep centered on indicator */
  left: calc(var(--an-space-4) + 8.5px);
}`}
  lang="css"
/>

## Standalone TimelineConnector

A standalone `TimelineConnector` component is also exported for building fully custom timeline layouts where you render steps manually:

<CodeBlock
  code={`import { TimelineConnector } from 'agent-native';

// Used between manually rendered TimelineStep elements
<TimelineConnector fillPercent={50} />`}
  lang="tsx"
/>

<PropsTable
  props={[
    { name: "fillPercent", type: "number", default: "0", description: "Fill percentage (0-100). Controls the height of the inner fill element." },
    { name: "className", type: "string", description: "Additional class on the connector root element." },
  ]}
/>

<Callout variant="info">
  The standalone TimelineConnector is not used by AgentTimeline internally. It exists for custom layouts where you compose TimelineStep and TimelineConnector yourself. For most use cases, the automatic `::before` connectors in AgentTimeline are the right approach.
</Callout>
