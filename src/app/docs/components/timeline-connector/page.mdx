# TimelineConnector

A vertical line drawn between steps to show sequential flow. Includes an inner fill element that animates to indicate progress between steps. Managed automatically by AgentTimeline, but available standalone for custom timeline layouts.

<FeatureList
  features={[
    "Fill percentage from 0-100 for progress indication",

    "Aligned to the center of step indicators",
    "Automatic fill logic when used inside AgentTimeline",
    "Class override support",
    "Respects reduced motion preferences",
  ]}
/>

  code={`import { TimelineConnector } from 'agent-native';

## Examples

### Fill States

When used inside AgentTimeline, fill percentages are set automatically based on the next step's status:

| Next Step Status | fillPercent |
|-----------------|-------------|
| `pending` | `0` |
| `running` or `streaming` | `50` |
| `complete` or `error` | `100` |

<LiveDemo title="Fill Percentages">
  <AnimatedConnectorDemo />
</LiveDemo>

### Building a Custom Timeline

Use TimelineConnector with TimelineStep to compose your own timeline layout:

<CodeBlock
  code={`import { TimelineStep, TimelineConnector } from 'agent-native';

function CustomTimeline({ steps }) {
  return (
    <div>
      {steps.map((step, i) => (
        <div key={step.id}>
          <TimelineStep step={step} />
          {i < steps.length - 1 && (
            <TimelineConnector
              fillPercent={
                steps[i + 1].status === 'complete' || steps[i + 1].status === 'error'
                  ? 100
                  : steps[i + 1].status === 'running'
                  ? 50
                  : 0
              }
            />
          )}
        </div>
      ))}
    </div>
  );
}`}
  lang="tsx"
  filename="CustomTimeline.tsx"
/>

### Styling

Override the connector appearance with Tailwind classes:

<CodeBlock
  code={`// Thicker, colored connector
<TimelineConnector
  fillPercent={75}
  className="bg-zinc-700 w-1"
/>

// Or via AgentTimeline's classNames prop
<AgentTimeline
  steps={steps}
  classNames={{
    connector: "bg-zinc-700 w-1",
  }}
/>`}
  lang="tsx"
/>

<Callout variant="info">
  The connector is positioned to align with the center of the step indicator circle. Its height is determined by the gap between steps.
</Callout>

## Automatic Behavior in AgentTimeline

You typically don't need to use TimelineConnector directly. When `showConnectors` is `true` (the default), AgentTimeline automatically renders connectors between steps with the correct fill percentages:

<CodeBlock
  code={`// Connectors are on by default
<AgentTimeline steps={steps} />

// Disable connectors
<AgentTimeline steps={steps} showConnectors={false} />`}
  lang="tsx"
/>

## CSS Classes

| Class | Description |
|-------|-------------|
| `an-timeline__connector` | Root container (2px vertical line, border-color background) |
| `an-timeline__connector-fill` | Inner fill bar (green/complete color, animated height transition) |

## Internal Structure

<CodeBlock
  code={`<!-- Rendered HTML -->
<div class="an-timeline__connector {className}">
  <div
    class="an-timeline__connector-fill"
    style="height: {fillPercent}%"
  />
</div>`}
  lang="html"
/>

The fill element transitions smoothly using `transition: height var(--an-duration-normal) var(--an-easing-default)`. When `prefers-reduced-motion: reduce` is active, the transition is disabled.
