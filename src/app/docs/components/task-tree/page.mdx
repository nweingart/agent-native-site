# TaskTree

Nested tree of tasks and subtasks with status indicators, expand/collapse, and optional connector lines. Visualize how an agent decomposes work into hierarchical steps.

<FeatureList
  features={[
    "Nested tree with unlimited depth",

    "Auto-expands nodes with running children",
    "Optional elapsed time display",
    "Vertical connector lines",
    "Controlled or uncontrolled expansion state",
    "Custom node content via render prop",
    "Full classNames override support",
  ]}

## Basic Usage

<CodeBlock
  code={`import { TaskTree } from 'agent-native';
import type { TaskNode } from 'agent-native';

const tasks: TaskNode[] = [
  {
    id: '1',
    label: 'Refactor auth',
    status: 'running',
    children: [
      { id: '1-1', label: 'Extract service', status: 'complete' },
      { id: '1-2', label: 'Update middleware', status: 'running' },
      { id: '1-3', label: 'Write tests', status: 'pending' },
    ],
  },
];

function MyTaskView() {
  return <TaskTree tasks={tasks} defaultExpandAll showElapsedTime />;
}`}
  lang="tsx"
  filename="MyTaskView.tsx"
/>

## classNames

| Key | Target |
|-----|--------|
| `root` | Root tree list |
| `node` | Each tree node `<li>` |
| `nodeRow` | Clickable row with chevron + indicator + label |
| `indicator` | Status indicator circle |
| `label` | Task label text |
| `description` | Description text below label |
| `children` | Children list container |
| `connector` | Vertical connector lines |

## Accessibility

- Root element has `role="tree"` with `aria-label`
- Each node has `role="treeitem"` with `aria-expanded`
- Children containers have `role="group"`
- All interactive elements have keyboard support (Enter/Space)
- `prefers-reduced-motion: reduce` stops spinner animation
