# ThinkingIndicator

Visual indicator for the "model is reasoning" phase — distinct from a loading spinner. Uses `useVisualMemory` for smooth enter/exit transitions.

<FeatureList
  features={[
    "Three animation variants: shimmer, dots, pulse",
    "Smooth enter/exit via useVisualMemory transitions",
    "Customizable label text",
    "Returns null when fully inactive (no DOM footprint)",
    "Accessible: role=\"status\", aria-live=\"polite\"",
    "Reduced motion: static indicators, no animation",
    "Full classNames override support",
  ]}
/>

## CSS Classes

| Class | Description |
|-------|-------------|
| `an-thinking-indicator` | Root container |
| `an-thinking-indicator--shimmer` | Shimmer variant modifier |
| `an-thinking-indicator--dots` | Dots variant modifier |
| `an-thinking-indicator--pulse` | Pulse variant modifier |
| `an-thinking-indicator--enter` | Enter animation state |
| `an-thinking-indicator--exit` | Exit animation state |
| `an-thinking-indicator__animation` | Animation container |
| `an-thinking-indicator__shimmer` | Shimmer bar element |
| `an-thinking-indicator__dot` | Individual dot element |
| `an-thinking-indicator__pulse` | Pulse circle element |
| `an-thinking-indicator__label` | Label text element |

## Accessibility

- Root element has `role="status"` and `aria-live="polite"`
- `aria-label` is set from the label prop (defaults to "Thinking")
- `prefers-reduced-motion: reduce` shows static indicators without animation
