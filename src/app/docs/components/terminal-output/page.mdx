# TerminalOutput

Streaming terminal/log output renderer with ANSI color support, auto-scroll, line numbers, and collapsible regions. Always renders with a dark terminal theme regardless of the app's color scheme.

<FeatureList
  features={[
    "ANSI escape code parsing (16 colors, bold, dim, italic, underline)",
    "Auto-scroll follows new lines, pauses when user scrolls up",
    "Streaming cursor indicator",
    "Exit code badge (green for 0, red for nonzero)",
    "Optional collapsible wrapper (details/summary)",
    "Dark theme always (conventional terminal appearance)",
    "Click handler per line",

<CodeBlock
  code={`import { TerminalOutput } from 'agent-native';

  const [lines, setLines] = useState<string[]>([]);
  const [isRunning, setIsRunning] = useState(false);

  return (
    <TerminalOutput
      lines={lines}
      isStreaming={isRunning}
      title="npm install"
      exitCode={isRunning ? undefined : 0}
    />
  );
}`}

## classNames

| Key | Target |
|-----|--------|
| `root` | Outer terminal container |
| `header` | Header bar |
| `title` | Title text |
| `exitCode` | Exit code badge |
| `body` | Scrollable body |
| `line` | Each output line |
| `lineNumber` | Line number |

## CSS Classes

| Class | Description |
|-------|-------------|
| `an-terminal` | Root container (always dark theme) |
| `an-terminal__header` | Header bar |
| `an-terminal__exit-code--success` | Green exit code badge |
| `an-terminal__exit-code--error` | Red exit code badge |
| `an-terminal__cursor` | Blinking streaming cursor |
| `an-terminal__ansi--{color}` | ANSI foreground color classes |

## ANSI Support

The built-in parser handles SGR escape codes:
- **Styles:** bold (1), dim (2), italic (3), underline (4), reset (0)
- **Colors:** 8 standard (30-37) + 8 bright (90-97) foreground colors
- **Backgrounds:** 8 standard (40-47) + 8 bright (100-107) background colors

The `parseAnsi` utility is also exported for standalone use.

## Accessibility

- Body has `role="log"` and `aria-live="polite"`
- Streaming cursor is `aria-hidden="true"`
- Exit code badge has `aria-label`
- `prefers-reduced-motion: reduce` stops cursor blinking
