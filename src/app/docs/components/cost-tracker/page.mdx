# CostTracker

Running tally of API costs per model and per call. Shows a summary bar with total cost and model breakdowns, plus a detailed table of individual API calls.

<FeatureList
  features={[
    "Summary bar with bold total cost and per-model pills",
    "Detailed table with per-call breakdown (model, label, tokens, cost, time)",
    "Group by model with subtotals, or flat list",
    "Clickable rows with keyboard support",
    "Scrollable table with maxHeight",
    "Custom currency symbol",
    "Full classNames override support",
  ]}
/>

## Basic Usage

<CodeBlock
  code={`import { CostTracker } from 'agent-native';
import type { CostEntry } from 'agent-native';

function MyCostView({ entries }: { entries: CostEntry[] }) {
  return (
    <CostTracker
      entries={entries}
      groupBy="model"
      onEntryClick={(entry) => console.log('Clicked:', entry.label)}
    />
  );
}`}
  lang="tsx"
  filename="MyCostView.tsx"
/>

## classNames

| Key | Target |
|-----|--------|
| `root` | Outer container |
| `summary` | Summary bar |
| `summaryTotal` | Total cost number |
| `summaryModel` | Model pill badges |
| `table` | Table wrapper |
| `tableHeader` | Table header row |
| `tableRow` | Each data row |
| `tableCell` | Individual cells |

## CSS Classes

| Class | Description |
|-------|-------------|
| `an-cost-tracker` | Root container |
| `an-cost-tracker__summary` | Summary section |
| `an-cost-tracker__summary-total` | Bold total cost |
| `an-cost-tracker__summary-model` | Model pill badge |
| `an-cost-tracker__table` | The table element |
| `an-cost-tracker__row` | Data row |
| `an-cost-tracker__row--clickable` | Clickable row with hover |
| `an-cost-tracker__group-header` | Model group header |
| `an-cost-tracker__table-total` | Total footer row |

## Accessibility

- Table uses `role="table"` with proper `role="row"` and `role="cell"`
- Column headers use `role="columnheader"`
- Summary has `aria-label`
- Clickable rows are keyboard accessible with `tabindex="0"`
