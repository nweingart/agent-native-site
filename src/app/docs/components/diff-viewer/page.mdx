# DiffViewer

Unified or side-by-side code diff renderer. Renders `DiffFile` data with colored line backgrounds, line numbers, hunk headers, and file status badges.

<FeatureList
  features={[
    "Unified and split (side-by-side) view modes",
    "Line numbers with old/new columns",
    "File header with path and status badge (added/modified/deleted/renamed)",
    "Hunk headers with @@ range markers",
    "Green/red line backgrounds for add/remove",
    "Click handler per line",
    "Scrollable body with optional maxHeight",
    "Full classNames override support",
  ]}
/>

## Basic Usage

<CodeBlock
  code={`import { DiffViewer } from 'agent-native';
import type { DiffFile } from 'agent-native';

function MyDiffView({ file }: { file: DiffFile }) {
  return (
    <DiffViewer
      file={file}
      view="unified"
      onLineClick={(line, hunkIndex) => console.log(line, hunkIndex)}
    />
  );
}`}
  lang="tsx"
  filename="MyDiffView.tsx"
/>

## classNames

| Key | Target |
|-----|--------|
| `root` | Outer container |
| `header` | File header bar |
| `headerPath` | File path text |
| `headerBadge` | Status badge (Added/Modified/etc) |
| `hunk` | Hunk container |
| `hunkHeader` | Hunk `@@` header line |
| `line` | Each diff line row |
| `lineNumber` | Line number cells |
| `lineContent` | Line text content |
| `addedLine` | Added line row |
| `removedLine` | Removed line row |
| `contextLine` | Context (unchanged) line row |

## CSS Classes

| Class | Description |
|-------|-------------|
| `an-diff-viewer` | Root container |
| `an-diff-viewer--split` | Applied in split view mode |
| `an-diff-viewer__header` | File header |
| `an-diff-viewer__header-badge--{status}` | Status-specific badge color |
| `an-diff-viewer__hunk-header` | Hunk range header |
| `an-diff-viewer__line--added` | Green background for additions |
| `an-diff-viewer__line--removed` | Red background for deletions |
| `an-diff-viewer__line--context` | Transparent background |

## Accessibility

- Root element has `role="table"` with descriptive `aria-label`
- Each line is `role="row"`, cells are `role="cell"`
- Hunk headers have `aria-label` with range info
