# TimelineArtifact

Renders a single artifact produced by an agent step — a file, code snippet, diff, or other output. Displays a kind badge and title, with expandable content. Used inside TimelineToolCallList to show step outputs.

  ]}

## Basic Usage

<CodeBlock
  code={`import { TimelineArtifact } from 'agent-native';
import type { Artifact } from 'agent-native';

const artifact: Artifact = {
  id: 'art-1',
  kind: 'code',
  title: 'utils.ts',
  content: 'export const sum = (a: number, b: number) => a + b;',
  language: 'typescript',
};

function MyArtifact() {
  return <TimelineArtifact artifact={artifact} />;
}`}
  lang="tsx"
  filename="MyArtifact.tsx"
/>

### Custom Renderer

Replace the default content display with syntax highlighting, a diff viewer, or any custom component.

<CodeBlock
  code={`<TimelineArtifact
  artifact={artifact}
  renderArtifactContent={(a) => (
    <pre className="rounded bg-zinc-900 p-3 text-xs font-mono overflow-x-auto">
      <code>{a.content}</code>
    </pre>
  )}
/>`}
  lang="tsx"
/>

## CSS Classes

| Class | Description |
|-------|-------------|
| `an-timeline__artifact` | Root artifact container |
| `an-timeline__artifact-badge` | Kind badge pill |
| `an-timeline__artifact-badge--{kind}` | Kind-specific badge styling (e.g. `--code`, `--diff`) |
| `an-timeline__artifact-title` | Artifact title text |
| `an-timeline__artifact-content` | Expandable content panel |

## Data Attributes

| Attribute | Element | Example |
|-----------|---------|---------|
| `data-artifact-id` | Artifact root | `"art-1"` |
| `data-artifact-kind` | Artifact root | `"code"` |
