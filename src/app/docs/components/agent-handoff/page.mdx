# AgentHandoff

Visualize multi-agent delegation chains. Shows agent cards connected by handoff arrows, with status indicators and optional inline step display.

<FeatureList
  features={[
    "Agent cards with status-colored left border",
    "Handoff arrows with task labels between agents",
    "Active agent highlighting with glow effect",
    "Vertical and horizontal layout modes",
    "Optional inline step display per agent",
    "Status dot with pulsing animation for running agents",
    "Click handler per agent card",
    "Full classNames override support",
  ]}
/>

## Basic Usage

<CodeBlock
  code={`import { AgentHandoff } from 'agent-native';
import type { SubAgent, HandoffEvent } from 'agent-native';

const agents: SubAgent[] = [
  { id: 'planner', name: 'Planner', status: 'complete', task: 'Decompose task' },
  { id: 'coder', name: 'Coder', status: 'running', task: 'Implement changes' },
  { id: 'reviewer', name: 'Reviewer', status: 'idle', task: 'Review code' },
];

const handoffs: HandoffEvent[] = [
  { id: 'h1', fromAgentId: 'planner', toAgentId: 'coder', task: 'implement auth', timestamp: Date.now() },
];

function MyAgentView() {
  return (
    <AgentHandoff
      agents={agents}
      activeAgentId="coder"
      handoffs={handoffs}
    />
  );
}`}
  lang="tsx"
  filename="MyAgentView.tsx"
/>

## classNames

| Key | Target |
|-----|--------|
| `root` | Outer container |
| `agent` | Agent card |
| `agentHeader` | Agent name + status row |
| `agentName` | Agent name text |
| `agentStatus` | Agent status text |
| `agentTask` | Agent task description |
| `handoffArrow` | Arrow connector between agents |
| `handoffLabel` | Task label on handoff arrow |
| `steps` | Steps container within agent card |

## CSS Classes

| Class | Description |
|-------|-------------|
| `an-agent-handoff` | Root container |
| `an-agent-handoff--vertical` | Vertical layout |
| `an-agent-handoff--horizontal` | Horizontal layout |
| `an-agent-handoff__agent--active` | Active agent card (glow + highlight) |
| `an-agent-handoff__agent--{status}` | Status-specific left border |
| `an-agent-handoff__dot--pulsing` | Pulsing animation for running agents |

## Accessibility

- Root element has `role="list"` with `aria-label`
- Agent cards have `role="listitem"`
- Active agent has `aria-current="true"`
- Clickable agents get `tabIndex`, Enter/Space keyboard support
- `prefers-reduced-motion: reduce` disables pulsing
