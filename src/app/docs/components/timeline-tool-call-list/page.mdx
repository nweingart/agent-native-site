# TimelineToolCallList

Renders a collapsible list of tool calls and artifacts for a step. Automatically expands when a tool call is in the `running` state. Used internally by TimelineStep when `showToolCalls` is enabled.

<FeatureList
  features={[
    "Collapsible container with tool call count badge",
    "Auto-expands when any tool call is running",
    "Renders both tool calls and artifacts",
    "Passes through custom renderers for tool content and artifacts",
  ]}
/>

## Basic Usage

<CodeBlock
  code={`import { TimelineToolCallList } from 'agent-native';
import type { ToolCall } from 'agent-native';

const toolCalls: ToolCall[] = [
  { id: 'tc-1', name: 'read_file', input: { path: 'src/app.ts' }, status: 'complete', output: '89 lines' },
  { id: 'tc-2', name: 'edit_file', input: { path: 'src/app.ts' }, status: 'running' },
];

function MyToolCallList() {
  return <TimelineToolCallList toolCalls={toolCalls} />;
}`}
  lang="tsx"
  filename="MyToolCallList.tsx"
/>

## Examples

### Auto-Expand on Running

The list automatically expands when any tool call has `status: 'running'`. No prop needed — it detects the status internally.

<LiveDemo title="Auto-Expanding List">
  <StandaloneToolCallListDemo />
</LiveDemo>

<CodeBlock
  code={`const toolCalls: ToolCall[] = [
  { id: '1', name: 'read_file', input: {}, status: 'complete' },
  { id: '2', name: 'edit_file', input: {}, status: 'running' },  // triggers auto-expand
];

<TimelineToolCallList toolCalls={toolCalls} />`}
  lang="tsx"
/>

### With Artifacts

Pass both `toolCalls` and `artifacts` to render them together. Artifacts appear below the tool calls.

<CodeBlock
  code={`import type { Artifact } from 'agent-native';

const artifacts: Artifact[] = [
  { id: 'a-1', kind: 'code', title: 'utils.ts', content: 'export const sum = (a, b) => a + b;', language: 'typescript' },
  { id: 'a-2', kind: 'diff', title: 'config.ts', content: '- port = 3000\\n+ port = 8080' },
];

<TimelineToolCallList
  toolCalls={toolCalls}
  artifacts={artifacts}
  defaultExpanded
/>`}
  lang="tsx"
/>

## CSS Classes

| Class | Description |

| `an-timeline__tool-call-list` | Root container |
| `an-timeline__tool-call-list--expanded` | Applied when expanded |

<Callout variant="tip">
  In most cases you won't use TimelineToolCallList directly. Instead, pass `showToolCalls` to AgentTimeline or TimelineStep and the list is rendered automatically for any step that has `toolCalls` or `artifacts`.
</Callout>
