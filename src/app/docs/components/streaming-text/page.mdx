# StreamingText

Token-by-token text renderer with a blinking cursor. Shows LLM output as it arrives, with optional simulated typing animation for demos.

<FeatureList
  features={[
    "Instant display or simulated typing via typingSpeed prop",
    "Three cursor styles: line, block, underscore",
    "Cursor auto-hides when streaming stops",
    "onStreamEnd callback fires when done",
    "Accessible: role=\"log\", aria-live=\"polite\"",
    "Reduced motion: solid cursor, no blink",
    "Full classNames override support",
  ]}
/>

## Basic Usage

<CodeBlock
  code={`import { StreamingText } from 'agent-native';

function MyChat() {
  const [content, setContent] = useState('');
  const [isStreaming, setIsStreaming] = useState(true);

  // content grows as tokens arrive from your LLM
  return (
    <StreamingText
      content={content}
      isStreaming={isStreaming}
      onStreamEnd={() => console.log('Done!')}
    />
  );
}`}
  lang="tsx"
  filename="MyChat.tsx"

## CSS Classes

| Class | Description |
|-------|-------------|
| `an-streaming-text` | Root container |
| `an-streaming-text__text` | Text content span |
| `an-streaming-text__cursor` | Cursor element |
| `an-streaming-text__cursor--line` | 2px vertical bar cursor |
| `an-streaming-text__cursor--block` | 0.6em wide block cursor |
| `an-streaming-text__cursor--underscore` | 2px bottom border cursor |
| `an-streaming-text__cursor--hidden` | Hides cursor when not streaming |

## Accessibility

- Root element has `role="log"` and `aria-live="polite"` for screen reader updates
- Cursor has `aria-hidden="true"` (decorative)
- `prefers-reduced-motion: reduce` shows a solid cursor without blinking
