# ContextBudget

Token budget meter showing context window usage. Visualizes input tokens, output tokens, system prompt, cache, and remaining capacity as a stacked bar or ring chart.

<FeatureList
  features={[
    "Horizontal stacked bar layout (default) or circular ring chart",
    "Segments for system, input, output, and cache tokens",
    "Legend with token counts and percentages",
    "Warning (yellow) and danger (red) threshold indicators",
    "Threshold callback for programmatic alerts",
    "Animated segment growth on mount",
    "Full classNames override support",
  ]}
/>

## Basic Usage

<CodeBlock
  code={`import { ContextBudget } from 'agent-native';
import type { ContextBudgetData } from 'agent-native';

function MyBudgetMeter({ budget }: { budget: ContextBudgetData }) {
  return (
    <ContextBudget
      budget={budget}
      onThresholdReached={(level) => console.warn('Context budget:', level)}
    />
  );
}`}
  lang="tsx"
  filename="MyBudgetMeter.tsx"
/>

## classNames

| Key | Target |
|-----|--------|
| `root` | Outer container |
| `bar` | The bar or ring element |
| `segment` | Each token segment |
| `label` | Inline segment label text |
| `legend` | Legend container |
| `remaining` | Remaining capacity label |

## CSS Classes

| Class | Description |
|-------|-------------|
| `an-context-budget` | Root container |
| `an-context-budget--bar` | Bar layout mode |
| `an-context-budget--ring` | Ring layout mode |
| `an-context-budget--warning` | Warning threshold reached |
| `an-context-budget--danger` | Danger threshold reached |
| `an-context-budget__bar` | The stacked bar |
| `an-context-budget__segment--{type}` | Segment by type (system, input, output, cache) |
| `an-context-budget__legend` | Legend below the bar |

## Accessibility

- Bar/ring element has `role="meter"` with `aria-valuenow`, `aria-valuemin`, `aria-valuemax`
- Descriptive `aria-label` with token counts
