# AgentTimeline

A vertical timeline component for rendering AI agent workflows with real-time status updates, parallel execution tiers, and human-in-the-loop approval gates.

<FeatureList
  features={[
    "8 step statuses: pending, running, streaming, waiting_approval, complete, error, skipped, cancelled",
    "Parallel execution tiers for concurrent steps",
    "Built-in approval gates with approve/reject actions",
    "Live elapsed time counters on running and completed steps",
    "Auto-scroll keeps the latest step in view",
    "Full keyboard navigation and ARIA support",
    "Fully customizable via classNames, CSS variables, and render slots",
  ]}
/>

## Basic Usage

<CodeBlock
  code={`import { AgentTimeline } from 'agent-native';
import type { AgentStep } from 'agent-native';

const steps: AgentStep[] = [
  { id: '1', label: 'Scanning repository', status: 'complete', description: 'Found 847 files' },
  { id: '2', label: 'Analyzing dependencies', status: 'complete' },
  { id: '3', label: 'Generating plan', status: 'running', startedAt: Date.now() },
  { id: '4', label: 'Applying changes', status: 'pending' },
  { id: '5', label: 'Verification', status: 'pending' },
];

function MyTimeline() {
  return <AgentTimeline steps={steps} />;
}`}
  lang="tsx"
/>

### Approval Gate

Block progress until a human approves. Wire up `onApprove` and `onReject` handlers.

<LiveDemo title="Approval Gate">
  <TimelineWithApproval />
</LiveDemo>

<CodeBlock
  code={`import { AgentTimeline } from 'agent-native';
import type { AgentStep, ApprovalRequest } from 'agent-native';

const [request, setRequest] = useState<ApprovalRequest | undefined>({
  id: 'gate-1',
  stepId: 'preview',
  title: 'Apply refactoring changes?',
  description: '3 files modified, 247 lines changed',
  createdAt: Date.now(),
});

<AgentTimeline
  steps={steps}
  approvalRequest={request}
  onApprove={(req) => {
    setRequest(undefined);
    // Start next step...
  }}
  onReject={(req) => {
    setRequest(undefined);
    // Cancel workflow...
  }}
/>`}
  lang="tsx"
/>

### Custom Render Slots

Replace the default step body or status indicator with your own renderers:

<CodeBlock
  code={`<AgentTimeline
  steps={steps}
  renderStepContent={(step) => (
    <div>
      <span className="font-bold">{step.label}</span>
      {step.toolCalls?.map(tc => (
        <div key={tc.id} className="text-xs text-zinc-500">
          Called {tc.name}
        </div>
      ))}
    </div>
  )}
  renderStepIndicator={(step) => (
    <div className="w-8 h-8 rounded-full bg-zinc-800 flex items-center justify-center">
      {step.status === 'complete' ? '✓' : step.status === 'running' ? '⟳' : '○'}
    </div>
  )}
/>`}
  lang="tsx"

## Compound Subcomponents

`AgentTimeline` exposes its internal building blocks for advanced composition:

| Component | Access | Description |
|-----------|--------|-------------|
| `TimelineStep` | `AgentTimeline.Step` | Individual step row |
| `TimelineConnector` | `AgentTimeline.Connector` | Vertical line between steps |
| `TimelineTier` | `AgentTimeline.Tier` | Parallel execution group |
| `TimelineApprovalGate` | `AgentTimeline.ApprovalGate` | Approval prompt |
| `TimelineSummary` | `AgentTimeline.Summary` | Status count badges |
| `TimelineToolCall` | `AgentTimeline.ToolCall` | Individual tool call row |
| `TimelineToolCallList` | `AgentTimeline.ToolCallList` | Collapsible tool call list |
| `TimelineArtifact` | `AgentTimeline.Artifact` | Artifact output display |

## Data Attributes

| Element | Attribute | Example |
|---------|-----------|---------|
| Step | `data-step-id` | `"step-3"` |
| Step | `data-status` | `"running"` |
| Tier | `data-tier-id` | `"parallel-1"` |
| Approval gate | `data-approval-id` | `"gate-1"` |

Use in CSS: `[data-status="error"] { background: red; }`

Use in Tailwind: `data-[status=running]:ring-2 data-[status=running]:ring-blue-500`

## Accessibility

- Timeline uses `role="list"` with each step as `role="listitem"`
- Running steps are announced as `aria-busy="true"`
- Approval gate buttons are real `<button>` elements with labels
- `onStepClick` adds `tabIndex={0}` and keyboard handlers (Enter/Space)
- Elapsed time uses `aria-live="polite"` for screen reader updates
- `prefers-reduced-motion: reduce` disables animations and uses `an-pulse` instead of `an-spin`
