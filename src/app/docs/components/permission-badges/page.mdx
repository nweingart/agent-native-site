# PermissionBadges

Show what tools and permissions an agent has access to. Renders granted permissions with green check badges and denied permissions with red X badges.

<FeatureList
  features={[
    "Inline pill badges (default) or grid card layout",
    "Green granted badges with check icon, red denied badges with X icon",
    "Optional category grouping with labeled headers",
    "Hide denied permissions with showDenied=false",
    "Tooltips via description on hover",
    "Clickable badges with keyboard support",
    "Full classNames override support",
  ]}
/>

## Basic Usage

<CodeBlock
  code={`import { PermissionBadges } from 'agent-native';
import type { Permission } from 'agent-native';

const permissions: Permission[] = [
  { id: 'read', name: 'File Read', granted: true, category: 'file' },
  { id: 'shell', name: 'Shell', granted: false, category: 'shell' },
];

function MyPermissions() {
  return (
    <PermissionBadges
      permissions={permissions}
      onPermissionClick={(p) => console.log(p.name, p.granted)}
    />
  );
}`}
  lang="tsx"
  filename="MyPermissions.tsx"
/>

## classNames

| Key | Target |
|-----|--------|
| `root` | Outer container |
| `badge` | Each badge pill/card |
| `badgeIcon` | Check/X icon wrapper |
| `badgeName` | Permission name text |
| `group` | Category group container |
| `groupLabel` | Category label header |

## CSS Classes

| Class | Description |
|-------|-------------|
| `an-permission-badges` | Root container |
| `an-permission-badges--inline` | Inline pill layout |
| `an-permission-badges--grid` | Grid card layout |
| `an-permission-badges__badge--granted` | Green granted badge |
| `an-permission-badges__badge--denied` | Red denied badge |
| `an-permission-badges__badge--clickable` | Clickable badge with hover |
| `an-permission-badges__group` | Category group wrapper |
| `an-permission-badges__group-label` | Category header text |

## Accessibility

- Root uses `role="list"` with `aria-label`
- Each badge is `role="listitem"` with `aria-label` containing granted/denied state
- Clickable badges have `tabindex="0"` and keyboard support (Enter/Space)
- Descriptions available via `title` attribute for tooltips
