# AgentStatusBar

Compact horizontal bar showing agent state plus optional metrics — tokens, elapsed time, cost, and model name. Only sections with data render.

<FeatureList
  features={[

    "Elapsed time from string or number (auto-formatted)",
    "Cost display with smart decimal precision",
    "Model name display in monospace",
    "Clickable status with keyboard support",
    "Full classNames override support",
  ]}

## classNames

| Key | Target |
|-----|--------|
| `root` | Outer bar container |
| `status` | Status section (dot + label) |
| `statusDot` | Status indicator dot |
| `statusLabel` | Status text label |
| `tokens` | Token usage section |
| `elapsed` | Elapsed time section |
| `cost` | Cost section |
| `model` | Model name section |
| `divider` | Vertical divider between sections |

## Accessibility

- Root element has `role="status"` and `aria-live="polite"`
- Each section has a descriptive `aria-label`
- Clickable status gets `role="button"`, `tabIndex={0}`, and Enter/Space keyboard handling
- `prefers-reduced-motion: reduce` disables dot pulsing
