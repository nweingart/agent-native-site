# TimelineSummary

Renders status count badges for a set of steps. Shows at a glance how many steps are complete, running, errored, or pending. Useful as a header or footer for your timeline.

<FeatureList
  features={[
    "Counts steps by status automatically",
    "Ordered display: complete, running, error, pending",
    "Only shows badges for statuses with at least one step",
    "Reuses tier badge styling for visual consistency",
    "Class override support",
    "Reactive — updates as step statuses change",
  ]}
/>

## Basic Usage

<CodeBlock
  code={`import { TimelineSummary } from 'agent-native';
import type { AgentStep } from 'agent-native';

const steps: AgentStep[] = [
  { id: '1', label: 'Scan', status: 'complete' },
  { id: '2', label: 'Analyze', status: 'complete' },
  { id: '3', label: 'Build', status: 'running' },
  { id: '4', label: 'Test', status: 'pending' },
  { id: '5', label: 'Deploy', status: 'pending' },
];

function WorkflowSummary() {
  return <TimelineSummary steps={steps} />;
}`}

## Common Patterns

### Timeline Header

Place the summary above your timeline as a progress overview:

<CodeBlock
  code={`function AgentWorkflow({ steps }) {
  return (
    <div>
      <TimelineSummary steps={steps} />
      <div className="mt-4">
        <AgentTimeline steps={steps} />
      </div>
    </div>
  );
}`}
  lang="tsx"
/>

### Dashboard Widget

Use the summary standalone as a compact status indicator:

<CodeBlock
  code={`function WorkflowCard({ name, steps }) {
  return (
    <div className="p-4 rounded-lg border border-border">
      <h3 className="font-medium mb-2">{name}</h3>
      <TimelineSummary steps={steps} />
    </div>
  );
}

// Render multiple workflow cards
<div className="grid grid-cols-3 gap-4">
  <WorkflowCard name="CI Pipeline" steps={ciSteps} />
  <WorkflowCard name="Deploy" steps={deploySteps} />
  <WorkflowCard name="Migration" steps={migrationSteps} />
</div>`}
  lang="tsx"
/>

## CSS Classes

| Class | Description |
|-------|-------------|
| `an-timeline__tier-header` | Root container (reuses tier header flex layout) |
| `an-timeline__tier-badge` | Each status count badge (pill shape, monospace) |

<Callout variant="info">
  TimelineSummary reuses the tier header and badge classes for visual consistency across the library. You can override these with the `className` prop or target them directly in CSS.
</Callout>

## Display Order

Badges always render in this order (skipping any with zero count):

1. **complete** — green
2. **running** — blue
3. **error** — red
4. **pending** — gray
